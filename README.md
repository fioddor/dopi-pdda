# Debian Release Observatory

An analytic data pipeline for studying the evolution of Debian package deploy-dependencies
shaped as a plug-in for debian observer.

# Using

See the [User Guide](docs/user-guide.md)

  - Software Bill of Materials (SBOM) in standard format.

    plug-in's specific architecture or design (data models, module contracts,
